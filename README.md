# 余波协议 / AFTERSHOT

浏览器 2D 多人射击对战。支持 2–4 人房间，使用房主权威 WebRTC 同步；不调用生成式 AI API。

## 本地运行

双击 `start-local.cmd`，或直接打开线上版本：

https://yuboxieyi.netlify.app/

如果系统没有把 `node` 加入 PATH，启动脚本会自动使用当前 Codex 环境中的 Node；找不到时则直接打开线上版本。

## 操作

- `W A S D`：移动
- 按住鼠标左键：显示攻击范围，并开始校准扇面
- 松开鼠标：手枪和狙击枪开火
- 按住鼠标：机枪持续连射并累积散布，停火后缓慢恢复
- 按住 `Ctrl`：疾跑，消耗体力
- 按 `Space`：滑铲，消耗体力并有 2.5 秒冷却
- 按 `Esc`：打开/关闭战术菜单；单人练习会暂停，联机中不会冻结其他玩家
- `1 / 2 / 3`：切换手枪、狙击枪、机枪
- `R`：换弹

## 联机

房主点击“建立房间”，将 6 位房间码发给朋友；朋友输入房间码加入。房主开始比赛，所有玩家状态由房主模拟并以约 20Hz 同步。PeerJS 公共信令只负责 WebRTC 握手，不保存对局数据。

## 地图

- `铸炉交汇`：工业管线、炉芯与对称箱子组成的短中距离火线。
- `雨港货场`：湿滑栈桥、货柜长墙与系泊设施组成的斜向交火区。
- `沙蚀中继站`：开阔沙脊、残骸和中继盘组成的远射与绕后路线。

地图在练习入口或房主房间中选择。联机开始前会同步给所有玩家，碰撞、出生点和视觉材质随地图一起切换。

角色使用分层俯视造型：背包、护肩、装甲躯干、头盔视窗和当前武器轮廓始终可见；本地玩家蓝色、敌方朱红，命中、冲刺和滑铲保留独立反馈。

战斗中采用严格 116° 主视锥和 620px 视野。视野随角色朝向旋转，并被掩体遮挡；扇形攻击预览和实际射线使用同一套障碍物求交，墙后目标既不可见也不会被射线穿透。

## GitHub Pages 部署

- `.github/workflows/deploy-pages.yml` 会把 `submission/` 发布到 GitHub Pages。
- Pages 默认地址：`https://treabnb.github.io/xuboxieyi/`
- 自定义域名：`https://xuboxieyi.cc.cd/`
- `submission/CNAME` 已设置为 `xuboxieyi.cc.cd`。
- GitHub Pages 工作流已成功部署；DNSHE 的 CNAME/扁平化 A 记录已解析到 GitHub Pages，HTTP 入口可用。
- HTTPS 证书由 GitHub Pages 自动签发，签发完成前浏览器可能显示证书域名不匹配。

DNSHE 中需要将 `xuboxieyi.cc.cd` 的记录配置为：

```text
类型: CNAME
主机记录: @
记录值: treabnb.github.io
TTL: 600 / Auto
```

如果 DNSHE 面板把 `xuboxieyi` 显示为主域名的子记录，则主机记录填写 `xuboxieyi`，记录值保持不变。DNS 生效后，在 GitHub 仓库的 Pages 设置中启用 HTTPS。

不建议直接在手机竖屏游玩；当前目标环境是桌面横屏鼠标操作。

## 数值

- 手枪：26 伤害，360 射程，12 发，按住后扇面 4.5° → 2.2°
- 狙击枪：58–92 伤害，760 射程，5 发，按住 1.35 秒后 18° → 0.7°，每次开火消耗 18 体力
- 机枪：9 伤害/发，430 射程，48 发；连射每 0.1 秒增加 1° 散布，最高额外 40°，停火后 3.4°/秒恢复；每次开火消耗 2 体力
- 手持机枪时移动速度降低 25%，即 165px/s
- 体力上限 100；疾跑每秒消耗 22 并提速 45%；滑铲消耗 30，冷却 2.5 秒；停用 0.9 秒后每秒恢复 15

进入练习或由房主开始对局时，游戏会尝试进入全屏并通过 Keyboard Lock 锁定 `F5`、`F12`、`Ctrl+R/W/T/N/L/S/P/U`、`Ctrl+Shift+I/J/C/R/P`、`Alt+←/→` 和 `Backspace`。Esc 菜单中也可手动重新启用“全屏防误触”。

`Ctrl+W` 是浏览器保留快捷键：普通窗口模式不允许网页静默拦截，因此游戏同时注册离开确认作为兜底。若浏览器拒绝全屏或 Keyboard Lock，会显示“离开此网站？”确认，而不能保证完全阻止关闭标签页。操作系统保留组合键同样无法由网页覆盖。

联机访客由房主开局时没有直接的浏览器手势权限，可按 Esc 打开战术菜单，再点击“全屏防误触”启用 Keyboard Lock。
- 生命 100，重生 3 秒，先到 15 次击杀或 150 秒结束

## 已知限制

- 房间依赖公共 PeerJS 信令与 WebRTC 网络连通性；严格企业网络可能需要自建 TURN。
- 房主权威适合朋友局，不提供竞技级服务端反作弊。
- 当前目标环境为桌面横屏鼠标操作。
